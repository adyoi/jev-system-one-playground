A desktop playground for composing and evaluating the Jev System One primitives — Choice, Score and Noul — in a 33% three-pane editor (State / Question / Result), with a dual visual builder ↔ raw JSON workflow.

> PRIMITIVES

TYPESHAPENOTES
choicecriteria → option routingone outcome per option
scorecriteria legends + levelsscalar severity / rubric
noulyes / no gateone question, one verdict

> FEATURES

[3-PANE EDITOR] — State context, typed questions and live results side-by-side.
[VISUAL + RAW] — Build with guided forms, inspect/edit the exact JSON payload in parallel tabs.
[ADD / DELETE / CLEAR] — Compose unlimited questions per evaluation; upsert by id, delete by id.
[LIVE EVALUATION] — Token-based matching of state against every primitive (simulated where the gateway is 404).
[PRESETS] — Choice (Routing), Score (Rubric) and multi-question Noul (Yes/No) starter packs.
